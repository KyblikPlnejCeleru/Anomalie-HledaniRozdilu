# Anomalie – Hledání rozdílů

3D hra o hledání rozdílů mezi dvěma zrcadlově umístěnými laboratořemi na vesmírné stanici.

## Obsah repozitáře

- `Anomalie-Unity/` – kompletní zdrojový Unity projekt (Unity 6000.3.22f1)
- `Anomalie-Windows/` – hotový Windows build (`Anomalie.exe` + datové složky)

## Jak spustit build

Rozbalit/skopírovat celou složku `Anomalie-Windows/` a spustit `Anomalie.exe`.

## Jak otevřít projekt

Unity Hub → **Add project from disk** → vybrat složku `Anomalie-Unity/`.

## Ovládání

WASD pohyb, SHIFT sprint, MEZERKA skok, levý klik oprava anomálie, ESC pauza.

## Tituly

Použity pouze vestavěné Unity primitivy, vlastní materiály a font Noto Sans Mono (SIL OFL). Žádné assety z Asset Store. Kód, scény, UI a texty vytvořil AI asistent (OpenCode / Big Pickle) na základě zadání (cca 95 % práce); člověk dodal zadání, zkontroloval hru a odevzdal ji.
